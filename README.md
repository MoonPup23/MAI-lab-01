# Первая лабораторная по Python

## Введение

CLI - приложение на Python, которое реализует калькулятор выражений и конвертер разных единиц. Калькулятор поддерживает: "+,-,*,/" и расставляет приоритет умножения и деления над сложением и вычитанием. Конвертер работает с температурой, весом, длину.

# Калькулятор
Калькулятор принимает на вход строку "EXPRESSION" -> далее функция tokenization разбивает строчку на токены -> функция validation проверяет корректность выражения -> функция calculation производит финальные вычисления

Поддерживаются:

   целые и вещественные числа;\
   операторы +, -, *, /;\
   унарные + и -;\
   пробелы между элементами выражения;\
   приоритет операций * и /.

Пример:

```bash
python -m toolkit calc "4 + 4 * 4"
```

Результат:
```
20
```


## Конвертер

Конвертер переводит из одной единицы измерения в другую. В конвертере 4 функции: 3 из них конвертируют определенные единицы измерения, а 4 вызывает 1 из них по надобности и проверяет на ошибки.

Поддерживаемые единицы:

   длина: mm, cm, m, km;\
   масса: g, kg;\
   температура: c, f, k.

Пример:
```
python -m toolkit convert 1 --from km --to m
```
Результат:
```
1000
```

## Подробнее о принятых решениях

Калькулятор

   1. Токенизация - на вход функции подается строка с выражением, далее с помочью буфера она обрабатывается и на выходе мы получаем список с токенами
   2. Валидация - на вход подаются токены из прошлой функции. Валидация же проверяет выражение на корректность последовательность, наличие знаков, правильность унарных знаков
   3. Вычисления - функция калькулятор получает валидированное выражение и обрабатывает уже его. В калькуляторе реализован приоритет выполнения операция

Вычисления происходят через Decimal

## Конвертер

Конвертер разделен на 4 функции:\
   length_convert() — перевод единиц длины;\
   weight_convert() — перевод единиц массы;\
   temperature_convert() — перевод температуры;\
   final_convert() — определяет группу единиц и запускает необходимое преобразование

За основу перевода в длине и массе бралась базовая единица: 1 mm или 1 g. Формула берет введенное значение, ищет в константе значение и перемножает - ```value * coefficient[from_unit] / coefficient[to_unit]```

В переводе температур  функция преобразует все через градусы Цельсия, используя данные для перевода под каждую единицу

Вычисления происходят через Decimal

## Политика округления Decimal

Все операции выполняются через Decimal. Округление происходит через ROUND_HALF_UP т.е. округляет в большую сторону если значение от 0.5
